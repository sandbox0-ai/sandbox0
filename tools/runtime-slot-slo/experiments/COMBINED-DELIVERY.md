## One state model, four policy controls

Replayed all 14,373 immutable NBD request shapes from 16 historical sandbox
identities. Every family starts with one empty, private, ideal-retention cache;
the historical `cached-new` label describes the trace source, NOT simulated node
cache warmth. This is not the real concurrent shared 128MiB runtime cache.

The combined policy uses joint mapping/data on a small-read mapping miss. With
mapping already available and the small payload absent, it uses a complete
original-frame group. Cache hits do not trigger speculation, newly fetched
ordinary mapping does not recursively trigger a group in that same decision,
and ordinary bulk dispatch is unchanged. Both mechanisms populate the SAME
original checksum/decoded-length cache identities.

The four toggles use identical model semantics. Adding the independent Coding
reductions would predict 264 windows, not the actual combined-model 269. Coding
data-group activations fall from 12 to 9 in the combination; seven joint packets
remain. This quantifies interaction, not five extra HTTP round trips or a timing
penalty. These counts are source transfer windows, not provider GET counts.

Disabled and joint-only controls match the reference models' complete event
sequences; both reference counters also match all sealed original/joint streams.
Two pure-bulk negative controls preserve
all non-root source schedules. Original baseline source schedules were previously
checked against the actual Reader; this turn did not rerun that complete Reader

## Necessary savings screen, not a speedup forecast

On each changed request, retain old mapping waits if ordinary mapping transfer
is still required, and old payload waits if ordinary data is still required.
Give every replacement joint/data group zero new cost. Union intervals per exact
sandbox and phase; do not add overlapping waits or multiply shared leaders.
Hold root duration fixed despite its larger joint selector.

- Historical cold Coding combined duration is about 2,666ms. Under those
  exceptionally favorable assumptions, remaining combined duration is
  1,821.894–1,839.482ms: only 160.518–178.106ms below 2s.
- Cold Node remaining duration is 1,785.234–1,797.294ms under the same screen.
- Before new data-group manifest/selector/encryption costs, modeled stored bytes
  already increase by 477,811 per Coding stream and 175,006 per Node stream.
- Coding creates one request with additional source work. That new cost, all
  replacement delivery costs, verification/decode, eviction and contention must
  be charged before admission. Nothing in this screen proves they fit the margin.

These are fixed-other-cost prioritization calculations, not architectural lower
bounds or a recovered guest/kernel dependency DAG. They use the historical
D-MAPPING-TRACE corpus, not the later HTTP-calibration latency population. Do not
combine the populations or claim cached-node/occupied-density acceptance.
