# Support

This repository is the archived historical open-source version of Sandbox0.
It no longer accepts issues or pull requests and receives no maintenance or
security fixes. Sandbox0 continues as a closed-source product.

- Product: https://sandbox0.ai
- Current documentation: https://sandbox0.ai/docs/sandbox
- Product feedback, bug reports, and security reports: contact@sandbox0.ai

Include a minimal reproduction, relevant version, and non-sensitive logs.
Never send API keys, tokens, credentials, or customer data in a report.
